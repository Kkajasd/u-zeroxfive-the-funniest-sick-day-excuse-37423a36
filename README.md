One line: the funniest sick-day excuse, written to `/output/entry.txt`.

> Can't come in today — my sleep tracker says I flatlined twice last night, so I'm staying home to make sure the third time isn't at my desk.

Entry for [make.fun's "The Funniest Sick-Day Excuse" bounty](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) — $2, top 3 split the pool, judged pairwise by an AI judge. The line is 139 characters, one line, no trailing newline.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. The program is deterministic: it writes the same single line every run, creates `/output` if missing, and never touches the network or reads files outside this repo.
